## 五万题实测

每份题单最大30题；满容量时生成测试替换30题草稿，不增加总容量。提交样本之间只由测试夹具恢复原草稿及相关投影，不把重复提交幂等快路径当作新提交性能。历史包含大量重复数学题，检验相同错题键的归约开销。

| 指标 | 本机P95 | 设计目标 |
|---|---:|---:|
| 生成30题并持久化 | 6.9ms | ≤500ms |
| 正常提交30题 | 58.3ms | ≤500ms |
| 历史首页查询20项 | 67.4ms | ≤1000ms |

原始样本已保存于`docs/evidence/performance-v0.1.0.json`，运行时完整测试日志/截图位于本地`work/qa`及`test-results`（不提交真实用户数据）。这里只包含程序生成的虚构夹具。上述指标未覆盖标准E1设备与输入到绘制P95，因此NFR02整体不标为完整通过。
